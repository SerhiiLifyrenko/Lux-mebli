# Технічне Завдання: Редизайн сайту Lux Kitchen 
 
## Ціль проєкту
Перебудувати сайт Lux Kitchen (https://lux-kitchens.vercel.app) з статичного лендінгу на лідогенеруючу воронку за принципом "Супермаркету цінної інформації". 
Базовий стек: Next.js + Tailwind CSS + Vercel.
 
## Завдання та вимоги
 
1. **Блок Hero (Перший екран):**
- Додати локальний маркер "Тернопіль і область" у надзаголовок 
- Змінити заголовок H1 на 4U-формулу з обіцянкою 3 кошторисів
- Додати фото Сергія з підписом (засновник студії Lux Kitchen)
- Замінити список переваг на "3 булети безпеки" (фіксована ціна, стандарти PUR та Blum, робота напряму зі спеціалістом)
- Кнопку CTA зробити якорем до квізу нижче
2. **Блок "Що дратує у виборі кухні" (Після Hero):**
- Додати новий блок з 3 картками (Pinterest vs реальність, будівельні "сюрпризи", шок-ціна)
- Картки реалізувати компонентами `<PainCard />` в 3-колонковій сітці
3. **Блок "Інженерні рішення" (Після "дратує"):**
- Додати новий блок з 3 пунктами: ергономіка життя, захист від вологи, кейс оптимізації
- Для кейсу зверстати компонент `<SavingsCase />` з before/after сумами
- Кейс реалізувати як окрему сторінку `/cases/case-study-1`, контент узгодити з Сергієм
4. **Блок "Чесно про гроші" (Після інженерних рішень):**
- Додати блок з заголовком "Скільки коштує кухня в Тернополі"
- Додати 3 `<BudgetCard />` картки з діапазонами цін та комплектацій 
- Додати таблицю "Що входить / не входить у вартість кухні"
5. **Блок "Квіз" (Після "чесно про гроші"):**
- Інтегрувати квіз-фреймворк з 5 кроками (форма, ремонт, розміри, важливе, терміни/бюджет)
- Фінальний екран квізу - збір контактів (Viber/Telegram) з обіцянкою 3 розрахунків
- Бекенд квізу реалізувати на Vercel Serverless Functions (клієнт - React-опитувальник)
- Лід-магніт (гайд) реалізувати як окрему сторінку `/pdf/kitchen-wiring-guide.pdf` після квізу
6. **Блок "Портфоліо з цінами" (Після квізу):** 
- Додати блок "Реалізовані кухні в Тернополі" з фільтрами (локація, тип)
- Картка проєкту - компонент `<ProjectCard />` з 1 фото, параметрами та фінальною ціною
- Портфоліо зберігати як Markdown-файли в `/data/projects`, генерувати сторінки кухонь через `getStaticProps`
- Відео-відгуки інтегрувати з YouTube плеєром, список відео в `/data/testimonials.yml`
7. **Блок "Що далі" (Перед футером):**
- Додати блок "Що буде після заявки" з таймлайном 5 кроків 
- Акцентувати увагу на інженерний виїзд та аудит за 800 грн (КЕВ)
8. **Сторінка Thank you page:**
- Створити окрему сторінку подяки `/thank-you` після форми квізу
- Додати кнопку "Завантажити PDF-гайд" з лід-магнітом
- Запропонувати забронювати інженерний аудит за 800 грн
- Дати посилання на Instagram-профіль Lux Kitchen для прогріву
9. **Інтеграції та трекінг:**
- Підключити Meta Pixel та Google Analytics 4 на всіх сторінках
- Налаштувати події (PageView, ViewContent, Lead) для квізу та цільових дій
- Реалізувати серверний трекінг через Segment на Vercel Cloud Functions 
10. **Оптимізація швидкості та оптимізація:**
- Налаштувати відкладене завантаження зображень через `next/image` з `loading="lazy"`
- Стиснути зображення через `sharp` або `next-optimized-images`
- Винести всі стилі в окремий CSS-бандл, мінімізувати його
- Перевірити у Lighthouse, PageSpeed Insights, випралений Core Web Vitals
## Схема екранів та порядок блоків
 
1. **Головна сторінка (/):**
   1. Hero (4U)
   2. "Дратує у виборі кухні" (3 картки)
   3. "Інженерні рішення" (3 пункти)
   4. "Чесно про гроші" (3 діапазони)
   5. Квіз (5 питань)
   6. Портфоліо з цінами (6-9 проєктів)
   7. "Що буде далі" (5 кроків)
2. **Сторінка Портфоліо (/portfolio):**
   1. Фільтр за локацією, типом
   2. Сітка з `<ProjectCard />` картками 
   3. Кнопка "Хочу так само" → Квіз
3. **Сторінка Дякуємо (/thank-you):**
   1. "Дякуємо, чекайте повідомлення"
   2. Кнопка "Завантажити PDF"
   3. Кнопка "Забронювати аудит"
   4. Посилання на Instagram
4. **Сторінка Кейс (/cases/case-study-1):**
   1. Обгортка для кейсу оптимізації
   2. Блоки "Завдання", "Рішення", "Результат"
   3. Кнопка "Зекономити так само" → Квіз
## Терміни та етапи
 
- **Дизайн:** 5 робочих днів
   - Прототип головної сторінки в Figma
   - Дизайн сторінок "Дякуємо" та "Кейс"
   - Дизайн `<ProjectCard />` та `<BudgetCard />` компонентів
- **Верстка:** 7 робочих днів
   - Адаптивна верстка блоків головної сторінки
   - Інтеграція Квізу, налаштування подій Meta Pixel
   - Верстка сторінок "Дякуємо" та "Кейс"
- **Завершення та тестування:** 3 робочі дні 
   - Перенесення контенту в Markdown, генерація сторінок
   - Налаштування серверного трекінгу 
   - Тестування, оптимізація швидкості
   - Фінальний прогін Lighthouse, PageSpeed Insights
**Загальний очікуваний термін:** 3 тижні з моменту старту робіт.
 
## Критерії приймання
 
1. Головна сторінка відповідає вимогам та порядку блоків з ТЗ.
2. Квіз інтегровано і він відправляє лід на бекенд.
3. Портфоліо генерується з Markdown-файлів, фільтри працюють.
4. Сторінки "Дякуємо" та "Кейс" відповідають вимогам ТЗ.
5. Сайт коректно трекає події в Meta Pixel та Google Analytics 4.
6. Сайт оптимізовано (Lighthouse показники 90+, TTFB < 200ms).
7. Код не містить помилок, збирається і деплоїться на Vercel.
