## 🎯 ЦІЛЬОВА АУДИТОРІЯ — ПОРТРЕТИ
 
### Первинна ЦА: Жінки 25–45, Тернопіль
**Три чіткі психотипи:**
 
#### Тип А — «Нарешті своя кухня» (25–34)
- Молода сім'я, перший ремонт або переїзд у нове житло
- Нічого не знає про матеріали — боїться помилитися
- Рішення приймає **емоційно**, підтверджує **логікою**
- Дивиться Pinterest, Instagram, TikTok за натхненням
- Головний страх: «Зроблять як у всіх / виявиться не те, що обіцяли»
- Тригери: «кухня мрії», «ідеальний ранок», «нарешті для себе», «так, як хочу я»
#### Тип Б — «Я вже обпікалась» (32–42)
- Або у неї вже є досвід поганого підрядника, або чула від подруги
- Скептична, вивчає деталі — читає договір, питає про гарантію
- Рішення приймає **логікою**, підтверджує **соціальним доказом**
- Дивиться відгуки, запитує у знайомих, порівнює кілька варіантів
- Головний страх: «Знову наберуть передоплату і зникнуть / затягнуть терміни»
- Тригери: гарантія, ціна в договорі, реальне виробництво, ім'я засновника
#### Тип В — «Хочу преміум і знаю що» (35–45)
- Розуміє різницю між Blum і китайською фурнітурою
- Вже бачила Fenix / Alvic у шоуруму або у подруги
- Рішення приймає **цінністю, не ціною** — але хоче чесності
- Читає довго, порівнює матеріали, цікавиться деталями
- Головний страх: «Переплачу і не отримаю те, за що платила»
- Тригери: назви матеріалів (Fenix, Blum SERVO-DRIVE), кейси «до/після», ексклюзивність

## 📱 META ADS — СТРАТЕГІЯ ТА НАЛАШТУВАННЯ
 
### Структура рекламного кабінету (рекомендована)
 
```
КАМПАНІЯ 1 — Awareness (CPM)
  └── AdSet: Жінки 25–45, Тернополь + 50км, Broad
      └── Креатив А: Reels «що під капотом» (Blum, Fenix)
      └── Креатив Б: Трансформація «до/після»
 
КАМПАНІЯ 2 — Traffic → DM або сайт (CPC)
  └── AdSet 1: Інтереси — ремонт, інтер'єр, нерухомість
  └── AdSet 2: Lookalike від підписників IG
      └── Креатив: Карусель «3 типи кухонь з цінами»
 
КАМПАНІЯ 3 — Conversions → Лід-форма або DM (CPL)
  └── AdSet: Ретаргетинг (відвідувачі сайту + взаємодія з акаунтом)
      └── Креатив: Засновник в кадрі + соціальний доказ
```
 
### Таргетинг — деталі
 
**Гео:** Тернопіль (основне) + Тернопільська область + радіус 40 км  
**Вік:** 25–45 (жінки як основна ЦА, чоловіки 30–50 як вторинна)  
**Пристрої:** Всі (мобільний пріоритет — 80%+ трафіку в ніші)
 
**Інтереси для стека (вибирати 3–5 на AdSet):**
- Ремонт будинку / Дизайн інтер'єру / Нерухомість
- IKEA / Кухні / Меблі на замовлення
- Pinterest / Houzz / Instagram (активні користувачі)
- Молодята / Переїзд / Новобудова
**Виключення:**
- Існуючі клієнти (Custom Audience з CRM)
- Конкуренти (за можливості)
### Бюджет та фази
 
| Фаза | Бюджет/міс | Мета | KPI |
|---|---|---|---|
| **Тест (0–30 дн.)** | $150–250 | Знайти робочий креатив | CTR >2%, CPM <$5 |
| **Масштаб (30–90 дн.)** | $300–500 | Ліди за прийнятним CPL | CPL <$15–25 |
| **Оптимізація (90+)** | $400–700 | Автоматизація найкращого | ROAS >3x |
 
### Правила налаштування (найважливіші):
 
1. **Завжди тестувати 3+ креативи** в кожному AdSet — ніколи не ставити одне оголошення
2. **Пріоритет — Advantage+ Shopping** або Advantage+ Audience для нового кабінету
3. **Бюджет на рівні кампанії** (CBO), не AdSet — Meta оптимізує краще
4. **Pixel на сайт обов'язково** — навіть якщо основна конверсія через DM
5. **Не вимикати оголошення перші 48–72 год** — фаза навчання алгоритму
6. **A/B-тест гачків** — перші 3 секунди Reels вирішують все
7. **Лід-форма** vs **DM** — тестувати обидва, для преміуму DM якісніші ліди
### Найефективніші формати для ніші (рейтинг):
1. 🥇 **Reels «процес» + голос засновника** — найвищий органічний reach + конверсія
2. 🥈 **Карусель «до/після» з цифрами** — найкраще для ретаргетингу
3. 🥉 **Статичне фото кухні з підписом** — для підтримки знання бренду
4. **Відгук клієнта в Reels** — сильний соціальний доказ
5. **Лід-форма «розрахунок вартості»** — для збору контактів
